Recursos docentes interactivos G-10 y T-20

Dos aplicaciones web que convierten contenidos técnicos sobre los goniómetros Wild G-10 y Wild T-20 en recursos visuales, guiados e interactivos.

Propósito del proyecto

Facilitar el aprendizaje de contenidos técnicos mediante recursos digitales accesibles desde el navegador, combinando explicación, exploración visual y práctica en una experiencia más clara y participativa.

Problema que resuelve

Los materiales técnicos pueden resultar difíciles de interpretar cuando se presentan únicamente de forma estática. Estas aplicaciones organizan el contenido en recorridos interactivos que ayudan a reconocer componentes, seguir procedimientos y consolidar lo aprendido mediante ejercicios prácticos.

Enfoque seguido

Se desarrollaron dos aplicaciones web independientes, una para cada goniómetro, con una estructura orientada al aprendizaje progresivo. El contenido se presenta mediante elementos visuales e interacción directa, y se publica con GitHub Pages para que pueda consultarse sin instalar software adicional.

Características principales

  • Exploración visual de los componentes de cada instrumento.
  • Procedimientos presentados de forma guiada.
  • Ejercicios prácticos para reforzar los contenidos.
  • Acceso directo desde un navegador mediante GitHub Pages.
  • Diseño web adaptable para distintos tamaños de pantalla.

Tecnologías utilizadas

  • HTML5 para estructurar los contenidos.
  • CSS3 para la presentación visual y el diseño responsive.
  • JavaScript para la interacción y los ejercicios.
  • GitHub Pages para la publicación de las aplicaciones.
